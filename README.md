# KURV

KURV is a polyphonic virtual-analog synth with oscillator-level spectral morphing.

```text
analytic saw / pulse coefficients
  -> one of four spectral transforms
  -> band-limit for the played pitch
  -> inverse FFT into a single-cycle buffer
  -> phase-continuous oscillator playback
  -> resonant low-pass
  -> amp envelope
```

This is synthesis, not an STFT audio effect. KURV does not FFT an incoming signal, stack sine oscillators, or run a delay-network disperser. It derives the source harmonics directly from the saw or pulse equation, changes their complex coefficients, and inverse-renders the playable cycle. Cycle changes are crossfaded to keep automation clean.

## Spectral effects

- **Phase Disperse** rotates harmonic phase with a curved group-delay law while anchoring the fundamental.
- **Harmonic Stretch** remaps upper partials away from the natural harmonic series.
- **Formant** imposes moving resonant spectral envelopes on the VA source.
- **Spectral Fold** folds high harmonics back around the selected spectral focus.

`Amount`, `Focus`, and `Shape` change meaning consistently within the selected effect. `Motion` updates the transform over time, and `Keytrack` moves the focus with the played note.

## Synth engine

- 16-voice polyphony with deterministic voice stealing
- Saw and variable-width pulse sources
- Velocity, poly pressure, per-note tuning, sustain pedal, and ±2-semitone pitch bend
- Amp ADSR
- Resonant low-pass with bipolar envelope amount
- Sample-accurate MIDI event handling
- Stereo oscillator phase width
- Optional audition drone, off by default

The editor's cycle display is generated by the same spectral oscillator used for sound generation. Keyboard capture is disabled so DAW shortcuts continue to work while the editor is focused.

## Run and build

```bash
cargo run --release --features standalone
cargo xtask bundle pure_va_dispersion_core --release
```

Uses [nice-plug](https://codeberg.org/RustAudio/nice-plug), nice-plug-egui, and realfft.

## Source layout

```text
src/
  lib.rs        plugin wrapper, parameters, sample-accurate MIDI
  editor.rs     responsive synth editor and exact cycle preview
  shape_osc.rs  analytic spectra, four transforms, inverse cycle renderer
  va.rs         source waveform and spectral-effect types
  voice.rs      fixed-allocation polyphonic voice engine and ADSR
  post.rs       resonant state-variable low-pass
```
