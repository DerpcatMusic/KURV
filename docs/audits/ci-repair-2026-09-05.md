# CI repair — 2026-09-05

This changes the local integration branch; it has not run on GitHub and is not a green full-plugin certification.

## Changes

- Pull requests, main pushes, merge groups, and manual dispatch trigger CI. Feature-branch pushes no longer duplicate their PR runs. Per-event/ref concurrency cancels superseded runs.
- Independent tracked first-party Rust formatting does not invoke Cargo metadata; every tracked Rust module is checked directly with rustfmt. Vendor code is excluded.
- Full-plugin jobs restore Matari-Audio/derpcat-activation at c6614660ab1a7e7a38197ce9a5801b86b566ec5e and Matari-Audio/derpcat-access at 36b6bb2adb7ccb76301554e7b8ce45137435ffdc. These are the existing signed-macOS workflow pins, not guessed repositories. Checkouts do not persist credentials.
- RELEASE_REPOSITORIES_TOKEN needs read-only contents access to both dependency repositories. No credentials were created, inspected, or changed here. Fork PRs cannot access it; move reviewed contributions to a trusted branch for full validation. No pull_request_target execution was added.
- Preflight recursively checks all local dependency manifests, including optional and transitive paths, plus the licensing module entry point. It fails with all missing inputs rather than synthesizing replacements.
- Full-plugin lint, library tests, and rt-paranoid allocation tests use --locked. Clippy/test logs are uploaded even on failure. Existing warning ratchet is unchanged.
- Public DSP CI explicitly installs Python 3.12 and NumPy 2.3.5; executes current-source VA checks, routing parity and deliberate dropped-parent negative control, 192 graph fixtures, 19,200 mixed-gain comparisons, real quantile tests, profiler safety, measurement controls and benchmark parser controls. It fetches history needed for pinned historical comparisons.
- VA adapter Cargo runs use --locked; generated source directories are cleared and watched so deleted/added modules cannot be hidden by a stale build cache.
- Stable final check `CI required` explicitly rejects failure, cancellation, missing jobs and skipped jobs. Configure branch protection to require this check once published; branch protection was not changed here.
