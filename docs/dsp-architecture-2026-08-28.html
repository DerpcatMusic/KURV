KURV realtime DSP architecture

What runs where, what “per voice” means, which optimizations survived measurement, and which experiments were deleted.

Signal ownership

Control/UIPublishes bounded parameters, graph edits, and immutable source data.
Audio callbackAdvances smoothers and control frames. No allocation, locks, I/O, or rendering.
Polyphonic noteOwns independent oscillator, modulation, filter, envelope, and noise history.
Ordered groupUnison sums inside each oscillator; later generators may consume earlier PM; filters process the note's stereo sum.
Host outputNote voices sum, then group gain/pan and output-pair routing apply.

Per voice means per polyphonic note, not per unison lane. A filter after each unison lane would multiply state and CPU. A filter after all notes are summed would be cheaper but would destroy note-specific modulation and couple every note through one state.

Audio-rate modulation boundary

Generator PM, AM, RM, and pan are ordered, same-group, earlier source to later carrier. They reuse the already-rendered source sample, have no runtime graph solver, cannot form a cycle, and keep independent state per note. LFO modulation of route depth stays in the block path.

One persisted route mode selects phase, bounded 0–2x amplitude, dry-to-bipolar ring, or bounded linear pan modulation. Mode changes reset depth so the existing smoother fades the old transfer function out. Lazy LFO-depth storage removed 7–9% from static routes: median-of-three matched 32-note results were PM 1.375, AM 1.428, RM 1.352, and pan 1.358 µs/frame; audio-rate LFO PM was 2.381 µs/frame. Every output remained finite. Feedback still needs a deliberate one-sample delay, bounded loop gain, reset semantics, and hearing-safe output control.

Audio-rate oscillator destinations currently include Shape/Noise Tilt, Pulse/Noise Gaps, pitch, level, pan, VA/Resynth phase, Warp/Noise Stereo, jitter, stereo X/Y, Grain tune/stereo, Rich dynamic, and generator-route depth. All four filter controls are audio-rate. Noise exposes Level, Pan, Tilt, Gaps, and Stereo but no pitch, unison, or phase controls; discrete voice count, unison layout, random-start policy, route mode, and analysis-heavy resynthesis controls remain control-rate.

Noise source contract

Noise shares oscillator identity, level, pan, ordering, routing, reset, and modulation behavior, but it is intrinsically single-lane. Its compact filter-height card places one filled DSP-faithful preview on the left and Level, Pan, Tilt, Gaps, and Stereo on the right. It exposes no pitch or phase controls, and old preset or automation values cannot restore unison processing.

Gaps is note-independent amplitude-quantized sample-and-hold noise that transitions into sparse random impulses. The preview normalizes Tilt-dependent source energy before applying Level and uses distinct left/right fills for Stereo. VA, Noise, and Resynth waveform previews all scale vertically with oscillator Level. Existing curve values retain their exact shape while the shared LFO/VA curve range extends monotonically from ±1 to ±4 for harder bends.
